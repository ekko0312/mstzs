# 🎯 面试题背题助手

像背单词一样背面试题 —— **手输答案 + AI 校验 + 关键词查题 + 进度统计 + 错题集**。

基于 `面试题.docx` 自动解析出 **378 道题**。默认的技术题库有 340 道；38 道 HR/行为题放在独立的「非技术题库」，需要在侧边栏主动选择。

---

## 快速开始

### 1. AI 判分

本地使用项目内的 `.env` 配置；线上使用 Streamlit Secrets 中的供应商、模型与 API Key 配置。

想换别的模型：直接在左侧「🤖 AI 判分设置」里选供应商 → 填 Key → 保存并切换。

支持的供应商：

| 供应商 | 默认模型 | 说明 |
|---|---|---|
| **DeepSeek** | `deepseek-chat` | **当前使用**。便宜、中文好，判分够用 |
| 阿里云百炼 | `qwen-max` | 质量高，按量计费偏贵 |
| 智谱 GLM | `glm-4-plus` | `glm-4-flash` 有免费额度 |
| 小米 MiMo | `mimo-7b-rl` | 小米自研 |
| 自定义 | — | 任何 OpenAI 兼容端点（本地 Ollama / vLLM 也行） |

> `.env` 和真实 Secrets 不提交到 GitHub；API Key 用于连接你所选的 AI 服务。

### 2. 启动

```bash
cd interview-trainer
./.venv/Scripts/python.exe -m streamlit run app.py
```

**最省事的用法：双击桌面上的「面试题背题助手」。**

它会自动启动服务、等几秒后弹出浏览器，指向 http://localhost:8501 。
关掉那个黑色命令行窗口 = 停止服务。

如果项目目录挪了地方，编辑桌面那个 `.bat`，把 `APP_DIR` 改成新路径即可
（或者重新跑一次 `python make_launcher.py` 让它自己更新）。

> 也可以直接双击项目里的 `start.bat`，效果一样。

## 四个页面

| 页面 | 作用 |
|---|---|
| **背题** | 出题 → 手输答案 → AI 逐要点判分 → 看得分/命中/缺失/错误 → 下一题 |
| **查题** | 按关键词搜索题干、参考答案和上下文，选择匹配题目后直接显示答案 |
| **错题集** | 按历史最低分排序，点开看当时漏了哪些要点，可一键专项练 |
| **统计** | 总题量/已背/平均分/连续打卡、各分类掌握度图、30 天趋势、记忆状态分布 |

### 主动查询题目

打开顶部的「查题」，输入关键词后按回车或点击「搜索」。例如输入 `HashMap`、`索引`，或用空格组合多个关键词，如 `Redis 持久化`。英文不区分大小写，全角英文也能匹配；同时包含所有关键词的题目才会显示，题干匹配优先。

搜索默认覆盖技术题库。可在「搜索范围」中选择某个分类、非技术题库，或「全部题库」。从「匹配题目」中选择一条后，下方直接展示完整题干、相关上下文和原题库参考答案。查题不需要 AI 判分，也不会计入背题记录或改变复习进度。

### 出题模式

- **复习优先**（默认）：优先出到期的复习题，没有再出新题
- **只背新题**：只出没背过的
- **只刷错题**：只出最低分 < 60 的
- **随机抽题**：只从当前选中的题库随机抽题；默认不会抽到非技术题

侧边栏的「题库 / 分类」默认选中「技术题库」。复习优先、新题、错题和随机模式都只从当前题库出题。想练 HR/行为题时，主动切到「非技术题库（主动选择）」即可；切回技术题库后，它们不会进入日常出题队列。

## 判分逻辑（要点覆盖制）

这是整套系统的核心，参考 Khan Academy 的 LLM 简答评分研究结论设计：

1. **给 AI 的是「评分要点清单」而不是「标准答案全文」** —— 要点式评分的一致性和准确率显著高于范例式。
2. 每条要点判三档：`hit`（命中）/ `partial`（部分命中，算 0.5 分）/ `miss`（未命中）。
3. 额外检测**事实性错误**（概念说反、张冠李戴），单独列出并扣分。
4. **要求 AI 给出 evidence**（引用你的原话），这样你能复核 AI 有没有判错。

题目没有具体参考答案、仅有补充说明时，AI 会根据题意和场景独立判断答案并评分。补充说明只作背景，不直接作为标准答案；未配置 AI 或无法生成有效评分时，不会把这次作答误记为零分。

实测 DeepSeek 判分能正确识别语义等价，比如把「方法名和参数都一样」
判定为命中「方法签名必须完全相同」。答错题时它也会直接指出来
（"你这道题答的是重写和重载的区别，跟题目问的接口和抽象类不是一回事"）。

### 分数 → 记忆评级

| 分数 | 评级 | 含义 |
|---|---|---|
| ≥85 | Easy | 答得完整，复习间隔拉长 |
| 70–84 | Good | 基本掌握，正常间隔 |
| 50–69 | Hard | 有遗漏，较短间隔重来 |
| <50 | Again | 没答对，很快再考一次 |

评级驱动 **FSRS 间隔重复算法**（Anki 新版默认算法）计算下次到期时间。

## 文件结构

```
interview-trainer/
├── parse_docx.py      # 解析 面试题.docx → questions.json
├── store.py           # SQLite 数据层 + FSRS 调度 + 统计查询
├── grader.py          # 多供应商 AI 判分（含独立评分与离线兜底）
├── supabase_store.py  # 云端个人记录与复习安排
├── cloud_connection.py # 云端连接异常处理
├── question_search.py # 本地与线上共用查题
├── answer_display.py  # 参考答案排版
├── questions.json     # 378 道题及场景、回答方向
├── app.py             # Streamlit 界面
├── data/
│   └── trainer.db     # 背诵记录（自动生成）
├── .env               # 本地 AI 配置，不提交到仓库
└── .venv/             # 虚拟环境
```

### 数据表

- `questions` — 题库（题目 / 参考要点 / 分类）
- `reviews` — 每次作答（我的答案 / AI 分 / 命中要点 / 缺失要点 / 评语 / 用时）
- `card_state` — 每题的 FSRS 记忆状态（调度用）

### 判分用了哪家模型？

每次作答都会把 `供应商:模型` 写进 `reviews.model` 字段，所以以后换模型了，
还能回溯统计「哪个模型判得更准」。

## 更新题库

改了 `面试题.docx` 后重新跑：

```bash
./.venv/Scripts/python.exe parse_docx.py
./.venv/Scripts/python.exe -c "import store; store.import_questions(force=True)"
```

> ⚠️ `force=True` 会清空题目表，**但保留 `reviews` 和 `card_state`**（背诵记录不丢）。

### 解析规则（改 docx 时注意保持格式）

```
2026年7月5日                                    ← 日期分组
==和equals的区别？两个都重写…？hashcode…？        ← 大题头（会被跳过）
==和equals的区别？                               ← 小节题（真正要背的）
==比较基本数据类型时比较值…                        ← 答案要点
  补充：xxx                                      ← 补充（不计分）
```

判定小节题的核心规则：**以？结尾，且下一行不以？结尾**。
含 ≥2 个问号的行视为「大题头」（把当天多个子问题串成一行），跳过。

## 已知限制

- **离线模式**（无 API Key）用的是字符重叠度粗判，准确度远不如 AI，只够跑通流程。
- 解析器是按你这套文档格式定制的。如果 docx 结构大改，需要同步调整 `parse_docx.py` 里的规则。
- 目前 378 题中约 3 处因原文格式特殊未识别，已记录在解析日志的 warnings 里。


## 云端连接故障与恢复

上线版使用 Supabase 保存账户、错题本和个人练习记录。题库保存在仓库中。

如果登录时或进入应用后提示云端服务无法连接：

1. 管理员打开 Supabase Dashboard，查看部署时所用项目的状态。
2. 如果状态为 **Paused**，点击 **Restore project / Resume project** 并等待恢复完成。
3. 如果项目正常，检查 Streamlit Secrets 中的 `SUPABASE_URL` 是否对应当前项目；项目域名应以 `.supabase.co` 结尾。
4. 服务恢复后点击应用中的 **重试连接**；登录过期时点击 **重新登录**。

Supabase 的免费项目可能因一段时间活动不足而自动暂停。官方说明：
https://supabase.com/docs/guides/platform/free-project-pausing

暂停的项目可能停止解析其域名，导致 DNS / NXDOMAIN 错误。官方排查说明：
https://supabase.com/docs/guides/troubleshooting/nxdomain-error-connecting-to-a-supabase-project

连接失败时应用显示可恢复的提示，不把无法读取的记录当作空记录，也不会切换到共享的本地数据库。
已经完成的评分和答案会保留在当前会话中，并标明云端保存状态。网络写入失败时不会自动重复提交；恢复后先查看统计页的最近作答记录，以免重复记录。若评分已经保存而复习安排更新失败，会分别提示。

尚未确认保存的内容仅保留在当前浏览器会话中。关闭或刷新页面前，请先复制本次答案。
